# Design: for-iteration

## D1 区间形式封闭（裁决 1）

仅 `start..end`，右排他（P2 单形式）。`..=` 不入第 1 章清单——含端写 `start..end+1`；开放端 `..end`/`start..` 不批准（一元后缀/前缀形式会引入切片语义，属集合/切片章节）。两者均 E0105 兜底。

## D2 优先级：第 12 档，最松，独立非结合档

放 `||` 之下（最松二元档），与 Rust 分层同构——LLM 对该分层熟悉（generate-check-fix 循环友好）；算术更紧使 `0..n-1` 免括号。独立成档而非并入第 9 档：比较与区间是两个概念（P4 清晰性），混档会使 `a < b..c` 变成 E0104 链拒绝——过度拒绝；独立档下 `a < b..c` 解析为 `a < (b..c)`，类型层拒绝（比较区间无意义），句法层不误伤合法形式。链 `a..b..c` → E0104（该码语义"链式非结合运算符"不变，注册表描述做枚举扩展）。

## D3 续行集 +1（闭集扩展）

设计意图是"一切二元运算符皆可尾随续行"；`..` 入二元类后不同步入集会造成不对称惊讶（`a +\nb` 续行而 `0..\n10` 断句）。同一变更内扩展闭集（行接续 Requirement 明文"extending it is a spec change"——本变更即该 spec change）。E0102 条目描述用类措辞（binary operator），无需改动。

## D4 词法 munch 钉死

maximal munch 单独即得正确切分：浮点须点两侧各有数字（第 1 章既定），故 `0.` 不成 float，数字 munch 停在 `0`；随后 `..` 成 token。`1.5..2.5` 同理切为 `1.5` `..` `2.5`。无需新规则——MODIFIED 只加清单项 + 钉死句 + Scenario 把可观察行为固定（防未来 lexer 实现引入"数字贪吃点号"回归）。

## D5 协议与组合子延后，路径命名

Iterable/Iterator 接口、迭代器自动满足 Iterable、可迭代性检查（v0.8 E0252 对应物）→ 类型章节成对修订（届时可能回填本段 E04xx——段位届时认领）。组合子 map/filter/... 另需闭包/Option/List → 更后修订；纯度规则（v0.8 E0504 对应物）同期。for 语句的求值语义（表达式恰一次求值、按序逐元素、每元素体执行一次）现在批准——与第 3 章批准 if 求值语义同层。

## D6 零新码：复用三码 + 不认领段位

本章形式层无新诊断：for 取值位置 → E0202（条目描述"another ratified valueless statement form"通类已覆盖，无需改条目）；区间链 → E0104（描述枚举扩展）；解构/开放端 → E0105（第 2 章兜底）；循环外 break/continue → E0201（第 3 章及条目已预写"the iteration chapter adds for"）。E0104 描述扩展属枚举扩展而非重定义语义（注册表稳定性规则禁 re-meaning，不禁同变更内 truthful 维护）。段位不认领——认领与分配同步是既有节奏（control-flow 4 码、match 2 码皆因分配而认领），无分配不占段。

## D7 数值区间的可观察语义

右排他、单位步进、start ≥ end 零元素——这三点在形式层批准（v0.8 range(start,end) 语义），否则示例不可写、语义悬空；Range 类型、非数值区间、Iterable 实现归类型章节。空区间的"零迭代"是 for 语义的自然推论（无元素则体零次执行）。

## D8 for 绑定形式：标识符或 `_`

`_` 绑定空（与第 2 章 `let _ =` 丢弃先例同构）；解构形式待元组模式（match 章节既定成对路径），此前 E0105。绑定逐次迭代独立作用域（不泄漏过循环）——别名/可变性语义归类型层。

## 备选方案（已拒）

- `..` + `..=` 双形式：见 D1，P2 与 munch 交互成本。
- `..` 并入第 9 非结合档：见 D2，过度拒绝 `a < b..c` 类形式。
- `..` 不入续行集：见 D3，不对称。
- 现在批准迭代器协议/组合子：层不属此（接口/泛型/闭包/Option/List 均未批准）。
- for 认领 E0400–E0499 段位：零分配不占段（D6）。
- v0.8 `range(start, end)` 等价展开写法：判为实现细节排除；语义以右排他/步进陈述。
