# Design: grammar-skeleton

## 决策

**D1 — 行接续取代显式分号（用户裁决，推翻推荐项与 v0.8 基线）。**
选项：显式分号 + 块值（v0.8 §21.1，推荐）/ 语句化块 + 显式 return / 换行敏感 + 省略分号。用户选三。后果：行结构进入语义；v0.8 §21.1 的"语句一律分号结尾"不继承，但其块值思想（末项表达式即块值）保留（D5）。P4 经由续行算法的完全性满足（每个 token 序列恰有一棵树或被拒），不触发第 0 章例外机制，无 ADR。

**D2 — 单侧尾 token 续行规则。**
边界判定只看**行尾 token**：行尾 ∈ 续行闭集（二元运算符、`=`、`.`）→ 无边界；否则边界。不看下一行首 token（双侧规则 = JS ASI 陷阱源，如 `a\n(b)` 被续成调用）。P1 论证单侧性：判定只需行内最后 token。已知锋利边缘（记录进规范 Scenarios，非缺陷）：`a` 行后随 `- c` 行 = 两条语句（不是 `a - c`）；续写必须尾随运算符或同行。语句起始类是固定集合：标识符/字面量/关键字/`(`/`{`/前缀 `! - ~`。

**D3 — 括号内换行不敏感；块内行规则适用。**
`(...)`、`[...]`（含属性 `#[...]`）内部换行无意义——参数表跨行自由。`{...}` 是块不是括号：块内每行按深度 0 规则推断边界。

**D4 — 续行集闭集，前导点风格被拒。**
`obj\n.method()` 中 `.` 起始行 → E0102（`.method()` 的 `.` 不能起始语句）。链式续行唯一路径 = 尾随 `.`（P2 唯一路径）。

**D5 — 块值规则（继承 v0.8 §21.1 思想，去分号化）。**
末项是表达式 → 块值；末项是语句或空块 → 无值（类型层由类型章节定形）。无分号后"丢弃"失去 `;` 手段 → 显式 `let _ = expr` 作为末项即无值（P5：副作用可见）。

**D6 — 优先级表从零裁决：Rust 式排位 + 比较/等同档非结合。**
v0.8 无表（缺口）。排位取 Rust 式（位运算 `& ^ |` **高于**比较）而非 C 式（低于、且夹在等同与逻辑之间）：C 的 `a & b == c` → `a & (b == c)` 是经典错源；Rust 式 `(a & b) == c` 符合直觉。比较与相等**合为一档**且**非结合**（用户裁决）：`a < b < c` 解析层即拒（E0104），杜绝 `(a<b)<c` 静默错误；显式分组 `(a < b) && (b < c)` 合法。11 档闭表。

**D7 — 赋值是语句，不是表达式。**
无链式 `a = b = c`、无条件赋值 `if x = 1`（E0103）。lvalue 骨架期 = 标识符；字段路径等随归属章节扩展。

**D8 — 骨架排除项与宿主关系。**
控制流/声明/类型规则/λ 各归其章（proposal 非目标五项）；它们以 MODIFIED 增量插入本章。`[` `]` 在词法闭集内但索引语法 `a[i]` 延后（无被索引类型之前无意义）；`..` 范围运算符不在词法闭集，随迭代章节作词法+语法**成对**增补——本章不预设。`->` `=>` 不是表达式运算符（声明/控制流章节使用）。

**D9 — 段内结构：E0100 预留，E0101–E0105 连续分配，E0106–E0199 预留。**
遵循第 1 章先例（段头边界预留 + 连续分配 + 注释声明预留）。E0105 意外 token 是解析失败兜底码（一码一义：专指"token 无法归入任何产生式"）。

**D10 — fmt 保行是派生不变量，本章不定义 fmt。**
行结构语义化 ⇒ 格式化器合并/拆分源行 = 改变语义。不变量记入 proposal 影响范围，由工具章节承接实现义务。本章不改第 0 章文本。

**D11 — 非权威示例节（用户裁决，2026-09-03）。**
第 2 章正文获得 `## Examples (non-authoritative)` 节，自带免责声明（冲突时 Requirements/Scenarios 优先）。机制走 **Terminology 先例**：章节级附属节在提升时组装，不在 spec 增量内（增量保持纯 Requirements，与 lexical/diagnostics 一致）；样例权威源存变更目录 `specs/grammar/examples.md`，提升时逐字并入（末条 Requirement 与 Terminology 之间），zh 孪生镜像注释译文。约束：示例只用**已批准表面**（评审清单中的 `fn` 声明与属性白名单示例因此替换为多行调用；`Int64` 以注释标注归类型章节）；代码注释遵循仓库语言约定（EN 章 EN 注释，zh 孪生译文）。

## 备选方案

- **双侧续行规则（JS 式）**：拒——下一行首 token 参与判定引入 `(`/`[`/`+` 续行陷阱，违 P1 局部性。
- **C 式优先级排位**：拒——位运算低于比较是错源（D6）。
- **比较左结合 + 类型层拦截**：拒（用户裁决）——类型错误晚于语法错误，修复指引不如 E0104 精确。
- **语句化块 + 显式 return**：随 D1 一并被裁决否决——if/match 表达式化会受阻。
