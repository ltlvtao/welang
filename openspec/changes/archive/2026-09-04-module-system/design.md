# Design: module-system

权衡 D1–D8：

## D1 — 急切 + 后序初始化（裁决 3）

每个模块的顶层初始化器在进程启动、`main` 之前恰跑一次；次序 = import 图后序，遍历自根模块的 import 按源序展开，模块内源序。备选惰性初始化的失败模式：初始化时机取决于首个使用点，一个模块的求值序不可从其自身读出（违 P1 局部可判定）；且惰性初始化与「初始化期 panic 无捕获边界」组合时，panic 可能落在任意调用点深处而非进程启动。急切的代价——进程启动做全部初始化——正是 v0.8 §63 的默认与多数后端语言的实践，且初始化器本身即「启动逻辑」。循环依赖在编译期已被 `E1301` 拒绝，后序总是全序，无需运行时裁决。

## D2 — 预导入边界与遮蔽语义（裁决 1）

预导入 = 外层作用域，不是关键字化：本地同名声明合法遮蔽，无碰撞诊断。这把 `Dyn`（ch10:227 悬置）与基类型名纳入同一规则——ch10 已裁定 `Dyn` 是标准作用域普通 PascalCase 名，非关键字；遮蔽即其必然后果。`E0404` 语义不变：只管模块自有名（声明 + import 名）之间的重复，预导入名不在模块名字空间内。集封闭在章文：增删名字须走本章程的 spec 变更，防止「标准库发版悄悄改语言表面」。备选全量 `import std.core` 使规范每章示例都携带 import 序言，破坏 P2 的最短可核对片段；备选可配置 prelude 引入一层间接，v0.8 无此概念。

## D3 — `E` 任意命名 sum（裁决 2）

v0.8 §42 的 `pub fn main() -> Result<(), Error>` 把 `Error` 写死为标准库预声明类型。ch14 已把错误位约束为「命名 sum 类型」——机制完备，无需钦点拼写。固定 `Error` 名的两个代价：标准库必须预声明一个泛用错误 sum（其变体集难以闭合），且与 D2 的可遮蔽性相缠（遮蔽 `Error` 后 main 失效？）。任意命名 sum 让每个程序声明自己的错误域，与 ch14 单一机制的立场一致。

## D4 — 解析优先级：std > 项目 src/ > 依赖缓存

v0.8 §63 只定了一条优先规则（std 不可被本地遮蔽）。本变更补全为三级：`std` 首段保留（声明式保留，无专码——本地文件在 `src/std/` 下只是不可达，不是错误）；项目 `src/` 次之；其余落依赖缓存。项目压缓存保证：一个依赖的名字永远不会劫持项目自己的模块路径，P1 确定性。补全的规则是 v0.8 未决处的裁决，非偏离——v0.8 沉默处本规范必须择一。

## D5 — E1303 与 E1304 分立（一类事实一个码）

「项存在但非 pub」与「项不存在」是两个事实：前者是可见性执法（E1303，remediation = 加 pub 或换 pub 项），后者是名字解析失败（E1304，remediation = 拼写或 import）。合并为一码（v0.8 §63 层面无专码）会让 remediation 不可机操（P7）。分立的判据机械可判：限定符是 import 名、且被导入模块声明该项 → E1303；否则 E1304。

## D6 — v0.8 代码映射与 E1305 并拢

E0110→E1301、E0112→E1302 一对一继承（报文含期望文件路径，§63 原文）。E0141 在 v0.8 只覆盖「main 缺 pub」一种情形；本规范并拢「缺失 main / 非 pub / 形状不符」为一码 E1305——三者同 remediation（把根模块的 main 修成 `pub fn main() -> Result<(), E>`），报文携带具体违规情形。偏离逐情形分码的理由：一码一义（9900 章）指的是一个码一个触发事实族，E1305 的事实族是「根模块的 main 不合约定」，而非三个无关事实。泛化参数化（`Result<(), E>` 而非固定 `Error`）见 D3。

## D7 — 初始化期 panic 即中止

`main` 之前无捕获边界：初始化器 panic 依 ch14 展开后进程中止。这不是新规则而是 ch14「abort 即捕获边界」的直接外推——捕获边界列表唯一，`main` 之前不存在任何帧可承载捕获。若未来并发章批准，任务边界捕获（ch14 R4 预留）同样不覆盖启动期：启动是单任务的。

## D8 — 无前向声明的循环拒绝

v0.8 §63 拒绝循环依赖且无前向声明，修复 = 抽第三模块。备选「允许循环 + 运行时懒初始化打破环」被否：环上的初始化序无确定解（D1 的失败模式）；备选 `friend`/`internal` 跨模块可见性级别被否：`pub`/module-local 二级已覆盖 v0.8 §45 的用例，级别增多即隐式性增多（P5）。本项目跨文件共享代码的规范答案是第三模块，与「一类事实一个权威位置」同构。
