# Design: types-foundations

## D1 · 六片切分的第一片

裁决 1 定案六片序列（基础→复合+所有权→sum+match 修订→接口+泛型→可迭代协议→函数类型+闭包），依赖单向、逐片独立生命周期。本片无依赖、纯增量：只批「有哪些基础类型、字面量如何定型、转换如何被拒绝、溢出如何表现、注解槽填什么、条件与块值如何类型化」。

## D2 · 字面量默认：Int64 / Float64（裁决 2）

兑现 ch1 欠账。后缀即显式类型指令（ch1 闭集后缀 ↔ 本章类型名一一映射，scenario 钉死）。不做上下文推断——与「参数不推断」同一立场（P1）。

## D3 · 一个码管所有混合：E0501

全面无隐式转换（裁决 3）不按「位宽/符号/家族」拆码：拒绝理由同一（操作数类型不同），修复路径同一（显式方法）。位宽/家族细节进 description 不进码位。覆盖面不限于操作数：绑定注解、实参对参数、返回表达式对声明返回类型，同为「类型一致位置」，一码同管（审查 F2 补全——`let n: Int32 = 42` 若无此条则行为未定义）。操作数场景引完整消息串 `E0501:`；一致位置场景用括号码形（E0202 先例），避免一码两消息串。方法名清单（toInt64/toBytes/...）归标准库章节——本章只立义务不列名单（避免在无方法解析机制的阶段虚构清单权威）。

## D4 · 溢出：编译期/运行时两况一义（裁决 4）

编译期可判（常量折叠可见）→ E0502 编译错误；运行时 → 检查陷阱「永不产出回绕值」。陷阱的构造名（panic）与捕获边界（Result 边界）归错误机制章节——本章只锁可观察不变量「never silently wraps」，机制中立（原则 10）。wrapping 必经显式方法（清单归标准库）。

## D5 · 类型引用文法：名字或模块限定名

注解槽（ch2 `name: type`、ch6 参数/返回）的填充物 = PascalCase 名字或 `module.Name`（与 ch6 import 名一致）。tuple/fn/泛型文法不存在——各自随归属章节经本章修订进入（本章 Requirement 明文此路径）。槽内非名字文法 → E0105（产生式不适配，与 ch2 一致）。名字是否解析到已批准类型依赖模块解析 → 模块系统章节（非目标 8）。

## D6 · 条件位置 Bool：一码双兑

E0503 同时兑现 ch3 条件类型化与 ch4 守卫类型化——两者本就是同一义务（条件位置操作数 Bool）。if/while/守卫三处在一条 Requirement 陈述，不拆三条。

## D7 · 块值类型化：ch2 欠账的最小兑现

有值块类型 = 末项表达式类型；无值块无类型。「无值块出现在要求类型处」的行为需要 Unit 才可定义 → 复合片（非目标 5），本章显式前向引用。

## D8 · 延后清单（显式非目标）

Never→sum 片；`()`/record/tuple/newtype→复合+所有权片；泛型应用/List→接口+泛型片；fn 类型→函数类型片；丢弃检查（需 Unit）→复合片；局部遮蔽→复合片；String 迭代协议→可迭代协议片（清单里陈述「逻辑迭代以 Rune 为单位」的事实，协议留待）；方法名清单→标准库；陷阱构造名→错误机制；名字解析→模块系统。

## D9 · 段位与三码

认领 E0500–E0599（owner 0700-types），分配 E0501（混合类型操作数）/E0502（整数溢出）/E0503（条件非 Bool）；E0500 与 E0504–E0599 预留本章修订。未认领段收窄为 E0600–E9999。注脚：declarations 的注入哨兵用了 E0501（从未注册、已还原）——该码首次真实分配即在本章，与 E0401 的先例同构。

## D10 · 零宿主修订

第二例纯 ADDITIVE 章节：ch1 字面量默认、ch2 块值类型化、ch3 条件类型化、ch4 守卫类型化、ch6 注解文法五处前向引用落地即消解，宿主零改动。

## 备选方案（被拒）

- **依上下文推断无后缀字面量**：同一字面量类型依位置而变，局部可判定性受损，与参数不推断裁决相悖——被拒（裁决 2）。
- **安全 widening 隐式转换**：少写转换换「同码异为」面——被拒（裁决 3）。
- **wrapping 默认 + 显式 checked 方法**：静默错误值是生成代码陷阱面，v0.8 已拒绝——被拒（裁决 4）。
- **本章一并批准 String 迭代协议**：需要 Iterable/Iterator 接口——拆至可迭代协议片（非目标 4）。
- **按混合家族拆多码**：拒绝理由与修复同一，一码足够；码位细分是噪音——被拒（D3）。
