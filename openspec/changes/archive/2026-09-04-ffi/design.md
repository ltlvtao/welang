# 设计记录：FFI——`foreign "c"`（第 19 章）

## 用户裁决（2026-09-04，四项均采纳推荐）

1. **复用签名+效果段必写**：块内声明 = ch6 签名形（无体）+ ch16 段拼写，段 REQUIRED。否决 v0.8 `effect io`/`ownership gc` 前缀行（效果段已有既定位置，第二种拼写违 P5；类别前缀与 ch8 类型级类别不同构）。
2. **跨界集 = 标量+String/Bytes+不透明句柄**：String/Bytes 仅参数位。否决宽映射与极小集。
3. **不透明类型 = 无字段类别化 record**：零新产生式。否决 `type Name: category`（ch9 冲突）与新关键字。
4. **回调 v1 不批准**：缺口登记。

## 关键设计决定

- **D1 字符串字面量恰 `"c"`**：块头字符串是 ABI 载体名而非后端枚举——ADR-0002 决策 4 锁定唯一合法值；他串 E1701（含 `"go"`：v0.8 语法同形但值域不继承，反例参考）。扩展 ABI = spec 层修订本章（ch1 关键字先例的字符串版）。
- **D2 段 REQUIRED + 裸 `effect` 纯声明**：普通声明省略=纯有体可查（ch16）；foreign 无体，声明是唯一证据——必写（E1703，E0740 对位）。但 ch16 段拼写「一或多标签」之下纯 foreign 函数写不出：引入**仅块内合法**的裸 `effect`（零标签）= 显式纯声明。这不是 ch16 修订——foreign 函数声明是本章自有产生式，其段的文法随声明走（「一或多标签，或裸关键字」）；ch16 主体不动。R2 场景钉住两形。
- **D3 顶层专用 E1702 而非 E0105**：ch6 修订后 foreign 块是已批准顶层项；其位置规则是本章自己的——专用码镜像 E0743 先例，比「未批准产生式」的 E0105 更准确（E0105 留给真正未批的语法）。
- **D4 不透明类型零新产生式**：ch8「零字段 record 合法」+类别前缀（`record`/`byval record`/`byres record`）+花括号组——块内声明形与 ch8 完全同构，仅以「位于 foreign 块内」获得不透明语义：We 侧无构造、无更新、无字段（E1707/E0604）。**E1707 的必要性是实打实的**：ch8 构造的「全字段恰一次」对零字段空真——`Socket { }` 会凭空造值，必须以本章规则关死（构造与更新同码：同为「凭空/复制造值」的出口）。byres 者的 impl Releasable 义务经 ch13 E1101 声明完备性既有检查自然继承——impl 体调 foreign close 函数是普通受检代码，零新机制。
- **D5 String/Bytes 仅参数位**：返回一个 `char*` 谁拥有、多长、怎么释放——C 侧无统一答案；把答案留给每个声明的文档是 P1 破口。参数位借用约定可一句话固定（调用期、勿持有）；返回位一律 E1706。取字符串的惯用法：不透明 CString + 长度查询 + 拷贝入调用方 Bytes——显式编组，全程可判定。
- **D6 Never 返回：允许+披露**：`-> Never` = 「不返回」之声明（abort/exit 语义）。编译器对普通 Never 的保证来自运行时（panic 族）；对 foreign Never 只能信声明——**本章唯一的信任点，正文明示**（v0.8 评审已识别此例外、并要求显式记录而非隐含略过——立场继承）。声明而返回 = 原生侧未定义行为，规范边界之外。
- **D7 效果零新规则**：调用 foreign 函数 = 普通调用，效果集 = 声明段，E1401 调用位裁决原样适用；自定义标签（模块标签/合格导入标签/内建标签）全部合法。E1406–E1499 段注释的「FFI 效果声明」预铺实际落位 E17xx——本变更刷新该注释（注册表描述维护先例：段注释是活文档）。
- **D8 资源零新规则**：所有权以类型跨界：byres 参数 = ch13 实参通道（义务随签名）；byres 返回 = 义务在绑定处附着（scope resource 接管）；三通道/单触发/组合位禁令（E1104/E1106）原样成立。本章只加类型、不加规则。
- **D9 回调缺口登记**：跨界集排除 fn 型（E1705 盖签名位）；fn 名转 C 函数指针的完整故事需要：回调体效果归属（稍后自原生帧运行、计入谁的声明）、运行时上下文（哪个任务）、调用约定细节——三者皆无已批答案。缺口登记于 R8，独立变更经完整设计再入（v0.8 §47.1 的 E0744 方案不继承：其「回调效果 ⊆ 声明效果」把归属问题藏进了检查式）。延后有两面：签名位 fn 型（E1705 盖）与 foreign 名值位（E0105 盖、方法值先例——ch12:40 值域明文「top-level fn of chapter 6」，foreign 名不在其中）；包装闭包 `|x| abs(x)` 覆盖全部 We 侧用途，零实用性损失（审查 F2 补钉）。
- **D10 链接归工具链**：符号绑定、名修饰、库搜索、调用约定变体——we build/链接器故事（工具链章，六片序 6/6）；机制中立纪律（ADR-0002 决策 5）：spec 只定可观察语义与检查。本章 R8 明文记界。
- **D11 v0.8 码映射**：E0740→E1703；E0741（缺 ownership 前缀）→消亡（类别入类型，D4）；E0742（resource 返回须配 byres+Releasable）→消亡（ch13 E1101 既有义务全覆盖）；E0743→E1702；E0744→延后（D9）。终局 7 码 E1701–E1707（E1700 + E1708–E1799 段内预留）。
- **D12 宿主最小面**：ch1 一句（`foreign` 兑付，`mut` 句式先例、零新场景）；ch6 两处（File structure 枚举+1 场景；fn 声明末句刷新、零新场景）+示例 D14。ch8/ch13/ch16 零修订——不透明形复用 ch8 产生式、资源义务复用 ch13、效果调用位复用 ch16，全部经引用组合（P5：一个事实一个权威位置）。

## P1 复核

- 跨界集：类型检查（类型引用 ∈ 封闭集），局部可判定。
- 段必写/裸段：产生式固定拼写，解析期可判。
- 不透明语义：「位于 foreign 块内」是声明位置事实；构造/更新关死是同一封闭类型集上的检查。
- String/Bytes 仅参数位：签名位置检查。
- 资源/效果：全部复用既有局部检查（E1401/E1101/E1104/E1106）。
